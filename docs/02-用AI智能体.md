# 02 用 AI 智能体替你跑

适合：有电脑，想把整件事交给 AI。
前提：手机打开开发者模式和 USB 调试（[带截图的教程](00-打开开发者模式.md)），用数据线连上电脑。adb 和 Python 没装也没关系，AI 会帮你装。

## 哪些工具能用

要选**能在你电脑上执行命令**的 AI 工具。网页聊天窗口执行不了命令，那种情况看 [03-用聊天AI](03-用聊天AI.md)。

| 工具 | 出品 | 能否执行命令 | 说明 |
|---|---|---|---|
| WorkBuddy | 腾讯 | ✅ | 桌面版，让它在本地工作目录里操作 |
| Claude Code | Anthropic | ✅ | 终端里运行，会读 `CLAUDE.md` |
| Codex | OpenAI | ✅ | 终端或桌面版，会读 `AGENTS.md` |
| Trae | 字节跳动 | ✅ | 用 Builder / SOLO 模式 |
| Cursor | Anysphere | ✅ | 用 Agent 模式 |
| DeepSeek / 豆包 / ChatGPT 网页版 | — | ❌ | 用 [03-用聊天AI](03-用聊天AI.md) |

## 怎么开场

先说清仓库在哪，再把下面那段话发过去。

**仓库已经在本地**（WorkBuddy、Cursor、Trae 这类桌面工具，把 AI 的工作目录设成这个文件夹就行）：

```text
在这个 android-ad-cleaner 文件夹里，读取里面的 AGENTS.md，然后帮我给连着电脑的这台手机去广告。
```

**仓库还没下载**（Claude Code、Codex 这类终端工具）：

```text
请克隆 https://github.com/rddmwmddr/android-ad-cleaner ，读仓库里的 AGENTS.md，
然后帮我给连着电脑的这台手机去广告。
```

## 再补六句话，能省掉大半来回

只说「帮我关广告」，边界是 AI 自己划的，关完才发现某个开关不该动。把这几条一起发过去：

```text
1. 每改一步之前先告诉我改什么、影响什么，我说「可以」你再动手。
2. 动手前先跑只读检查（check）和快照（backup）。
3. 拿不准的开关先问我，别替我决定，尤其别关掉别处的功能。
4. 读屏连不上就停下来说明是谁占着，别反复重试。
5. 跑的时候提醒我别碰手机；跑完用表格说清关了什么、哪些没关、为什么。
6. 结束提醒我关开发者模式。
```

每一条挡掉的坑都是真实踩过的：

| 这句 | 挡掉什么 |
|---|---|
| 1 | AI 一口气跑完九段，你事后才发现某个开关不该关，还得自己一个个找回来 |
| 2 | 直接改，出问题没有对照，说不清原样是什么 |
| 3 | 「推荐服务」这类总开关被顺手关掉，负一屏的天气、步数、快递卡片一起消失 |
| 4 | 读屏被 GKD、自动记账之类占着，AI 反复重试白等十几分钟（见 [11-读屏冲突](11-读屏冲突与功能通知保护.md)） |
| 5 | 你中途碰了手机，点击全部落空，AI 却报「入口未找到」 |
| 6 | 开发者模式一直开着，AI 也不会主动提 |

## AI 会依次做这些事

1. 读 `AGENTS.md`（仓库还没下载时先克隆）。
2. 检查 adb 和 Python，缺什么装什么。
3. 运行 `run.py devices`，告诉你认到了哪台手机、有没有现成机型脚本。
4. 存一份改动前的快照。
5. 跑机型脚本，或者照清单一页一页关。
6. 列出营销通知渠道，给你看清单，你点头后关掉。
7. 检测快应用，问你要不要挂起广告包、关掉快应用。
8. 收尾，汇报关了什么、没关掉什么。
9. 提醒你关闭开发者模式。你说「帮我关」，AI 会从电脑上关掉，连接随之断开。

## AI 会问你的事

| AI 问 | 你怎么答 |
|---|---|
| 手机锁屏了，请解锁 | 解锁手机，屏幕保持亮着 |
| 认到多台设备，处理哪一台 | 说型号或序列号 |
| 这些营销通知渠道要关吗 | 看清单，有想保留的就说出来 |
| 要不要挂起这几个广告包 | 你决定。挂起可以还原 |
| 浏览器首页要不要换成简洁版 | 你决定 |

## 跑的时候

- 手机保持亮屏、解锁、插着线。
- 不要动手机。脚本在点屏幕，你一碰就乱。
- 有机型脚本的机型，全程 4 到 6 分钟。没有机型脚本的机型，AI 要一页一页找，时间长一些。

## 跑完以后

1. 打开下拉搜索、负一屏、应用商店、浏览器，确认功能正常。
2. 让 AI 把这次的路径存成机型脚本，下次同型号几分钟跑完。
3. 愿意分享的话，把机型脚本提交成 PR，见 [04-给新机型写脚本](04-给新机型写脚本.md)。

## 常用的追加指令

```text
只跑浏览器和主题两段。
把这台手机的路径存成机型脚本。
把挂起的包全部还原。
列出这台手机现在还开着的营销通知。
读屏连不上，先帮我查是哪几个 App 占着的。
这台是新系统，帮我确认机型脚本的入口还对得上。
把这次踩的坑补进 AGENTS.md 和 CHANGELOG。
```

## 一次真实的开场（一加 15T / ColorOS 17，WorkBuddy 桌面版 + Windows 11）

实际用起来是这样，可以直接照抄：

```text
在这个 android-ad-cleaner 文件夹里，读取里面的 AGENTS.md，然后帮我给连着电脑的这台手机去广告。
每一步改之前告诉我要改什么。
```

AI 会先停下来告诉你：认到的是哪台机器、有没有对应机型脚本、这把要跑哪几段、每段关什么留什么，等你点头。中途它发现这台机器没有专属脚本、只能借用同品牌旧脚本时，会说明风险再问你要不要继续——这时候别急着说「全跑」，先让它跑一段看看入口对不对。

九段跑完的实际结果（可作为预期参照）：

| 项 | 结果 |
|---|---|
| 广告跟踪 | ColorOS 17 变成了**逐应用列表**（165 个），一个个关掉 |
| 浏览器 / 主题商店 / 游戏中心 | 各关掉 1 到 3 个广告开关，功能不受影响 |
| 营销通知 | 21 条渠道，先给清单让你剔掉工作类通知，再关 |
| 广告包 / 快应用 | 挂起 `com.opos.ads`、`com.heytap.pictorial`，快应用保留平台框架 |

三处需要人工介入的地方：读屏被 GKD 和自动记账占着（暂停后才通）、负一屏右滑进不去、桌面下拉打开的是通知栏而不是搜索页。这几处 AI 会如实报「跳过 + 原因」，不会瞎点。
